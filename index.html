K

Буква K — Общее количество пикселей

Пространственное разрешение изображения
Растровое изображение представляет собой сетку из точек (пикселей). Буква K обозначает общее количество всех пикселей изображения.
Оно находится перемножением ширины на высоту:
K = X × Y = ширина × высота (пикселей)
Пример: если разрешение картинки 512 × 512 пикселей, то K = 512 × 512 = 262 144 пикселя.

I

Буква I — Информационный объём

Полный объём файла изображения целиком
Заглавная буква I обозначает полный объём графического файла. Он равен произведению общего числа пикселей на объём одной точки:
I = K · i

В задачах объём часто задан в Кбайтах. Для расчётов в битах его переводят:

1 Кбайт = 1024 байта = 1024 · 8 бит
I = K · i
Общий объём = (Все пиксели) × (Память на 1 пиксель)

N

Буква N — Мощность палитры

Количество доступных цветов в изображении
Буква N обозначает количество цветов в палитре. Она связана с глубиной цвета i формулой Хартли:
N = 2i
Если i = 1 бит → N = 21 = 2 цвета
Если i = 2 бита → N = 22 = 4 цвета
Если i = 4 бита → N = 24 = 16 цветов
Если i = 8 бит → N = 28 = 256 цветов
